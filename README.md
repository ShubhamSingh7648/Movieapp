# 🎬 CINEMAN - Movie Discovery Platform

A full-stack movie search and management application built with the MERN stack.

## Features
✅ Search 280,000+ movies and TV series
✅ User authentication with JWT
✅ Add movies to favorites
✅ Create and manage custom playlists
✅ View detailed movie information (cast, ratings, plot)
✅ Responsive design for all devices
✅ Profile management with image upload

## Tech Stack
**Frontend:** React.js, React Router, Context API, Tailwind CSS
**Backend:** Node.js, Express.js, MongoDB, Mongoose
**Authentication:** JWT, Bcrypt
**API:** OMDB API
**Deployment:** Vercel (Frontend), Render (Backend)
